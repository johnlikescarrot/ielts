# Changelog

All notable changes to Focus IELTS are documented here.

## [0.1.0] - 2026-09-27

### Added

- Firefox Manifest V3 extension with a compact review popup and full Studio.
- Local-only cards, interval scheduling, quick capture, backup import/export, English, and Vietnamese.
- Browser-native rehearsal playback and optional local microphone recording.
- Astryx-based React interface, strict TypeScript, 100% tested core coverage, and Super-Linter CI.
