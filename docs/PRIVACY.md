# Privacy policy

**Effective date:** 27 September 2026

IELTS Forge is designed so that the easiest way to use it is also the most private way.

## Data handling

IELTS Forge stores the following in Firefox's local extension storage:

- phrases and notes that you explicitly save;
- source title, URL, and nearby text for a saved phrase;
- review scheduling state;
- practice session duration and optional exercise score;
- language, daily goal, target band, exam date, and motion preference.

This data stays on your device. IELTS Forge does not operate a server, create an account, include analytics or advertising, or transmit study data to the maintainers or another company.

## Page access

The extension requests `activeTab` and `scripting` permissions. It reads the current text selection only after you open the extension and activate **Capture from page**. It does not request access to all websites, run a persistent background script, or collect browsing history.

## Microphone

A speaking drill can request microphone access. Audio is held in the current browser page as a temporary object URL so that you can replay it. IELTS Forge does not upload or permanently store the recording. Closing or reloading the page releases it; Firefox controls the microphone permission.

## Export and deletion

You can export all persistent data as a readable JSON file from Settings. You can delete individual cards or erase all local data. Removing the extension also removes its Firefox local storage under normal browser behavior.

## Network requests

The packaged extension contains its code and styles. It does not fetch remote code, fonts, prompts, definitions, or AI results. A source link saved with a card is opened only if you choose to use it.

## Changes

Material privacy changes should be documented in this file and the release notes before a release. Any future feature that requires network transfer must be opt-in, clearly disclosed, and compatible with the project's free and login-free commitments.

Questions and security reports can be filed in the repository's issue tracker without including private study content.
